# Logo y foto principal

- `logo.png` (o `logo.svg` / `logo.webp`): el logo a color del encabezado. Si no existe, se
  muestra un logotipo de texto.
- `logo-white.png` (o `.svg` / `.webp`): la versión blanca, para fondos morados como la ola del
  pie de página.

Para la foto principal de la página de inicio, guarda `src/assets/hero.jpg` (o .png/.webp),
vertical, mínimo 1000 px de ancho.

Las otras fotos del sitio (tratamientos, categorías, círculos destacados y `gracias.jpg`) se
describen en `src/assets/services/README.md`.

Cualquiera de estos archivos se puede reemplazar por un original de mayor resolución con el mismo
nombre; el sitio lo usará al compilar sin más cambios.
