# Logo

Guarda aquí el logo original como `logo.svg` (preferido), `logo.png` o `logo.webp`.
Al compilar, reemplaza automáticamente el logotipo de texto del encabezado y del pie de página.

Para la foto principal de la página de inicio, guarda `src/assets/hero.jpg` (o .png/.webp),
cuadrada, mínimo 1100 px.
